# PaliGemma Image Captioning

Fine-tuned PaliGemma-3B vision-language model for generating image captions.

## Model Details
- **Base Model:** google/paligemma-3b-pt-224
- **Fine-tuned Model:** Donald8585/paligemma-caption-finetuned
- **Method:** LoRA (Low-Rank Adaptation)
- **Task:** Image-to-Text (Image Captioning)

## Usage
Upload an image and get an AI-generated caption!
